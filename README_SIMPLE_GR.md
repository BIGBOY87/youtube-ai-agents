# BANG IT UP MUSIC — YouTube AI Agent

Άνοιξε πρώτα το `START_HERE_GR.txt`.

## Το μόνο αρχείο που βάζεις εσύ
`client_secret.json`

Μπαίνει στον ίδιο φάκελο με το `main.py`.

## Windows
1. `1_INSTALL_WINDOWS.bat`
2. `2_CONNECT_YOUTUBE_WINDOWS.bat`
3. `3_RUN_AGENT_WINDOWS.bat`

## Mac/Linux
1. `bash 1_install_mac_linux.sh`
2. `bash 2_connect_youtube_mac_linux.sh`
3. `bash 3_run_agent_mac_linux.sh`

## Outputs
Τα αποτελέσματα μπαίνουν στον φάκελο `outputs`.
