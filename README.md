# BANG IT UP MUSIC AI Agents v6 - Autonomous Video Creator

Adds controlled-autonomy video project generation, initiative engine, approval queue, SEO/Shorts/social drafts, and safety policy.

Render build command: `pip install -r requirements.txt`

Render start command: `gunicorn app:app`

Required env vars: `YOUTUBE_API_KEY`, `YOUTUBE_CHANNEL_ID`.

Public actions still require approval. No fake views, fake subscribers, spam comments, or bot engagement.
